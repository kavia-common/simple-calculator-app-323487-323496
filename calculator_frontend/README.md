# calculator_frontend (Swift)

This container is the Swift-based calculator frontend.

## Structure

- `CalculatorFrontend/` — Swift Package (executable) containing the app code
  - `Sources/CalculatorFrontend/` — app entry point and UI
  - `Tests/CalculatorFrontendTests/` — placeholder tests

## How to build/run (Swift Package Manager)

```bash
cd CalculatorFrontend
swift build
swift run
```

> Note: This scaffold provides an initial SwiftUI-based calculator UI and logic skeleton. If this project is intended to be an actual iOS app target (Xcode `.xcodeproj`), that can be added in a follow-up step.
